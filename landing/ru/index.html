Для вашего SPA

Админка подключается. Фронт остаётся твоим.

HCMS — бэкенд, которого не хватает SPA: визуальная схема, REST и нормальный /admin. Без самописного CRUD.

Drop-in /admin

Полная админка на PHP-хостинге. Редакторы не лезут в репозиторий фронта.

REST для React / Vue / Next

Публичный /api/{slug}: пагинация, поиск, сорт, фильтры. Bearer и CORS из коробки.

OpenAPI / Swagger

Спека /api/openapi.json, UI /api/docs — из опубликованной схемы.

Для команды

Вход, роли и формы без боли

Свежие доработки админки: OAuth, понятные роли editor/viewer, антиспам на публичных формах, email из коробки.

Вход под команду

Google и Telegram плюс TOTP 2FA. Владелец на пароле; редакторы могут подключить соцвход.

Роли без жаргона

Выдай контент-менеджеру доступ к записям — или только просмотр админки. Схема, пользователи и система остаются у владельца. Сверху — ACL на ресурсы.

Формы и email

Антиспам на public.create: honeypot, тайминг, капча, блоклист. Отправка через Resend, Postmark или Mailgun.

API за минуты

От типа контента до живого /api/{slug}

Схема — source of truth для SQL, валидации, REST, админки и OpenAPI.

Типы полей под реальные приложения

String, richtext, relation, media, slug, enum, json, даты — опубликовал и получил миграцию.

Запросы как ожидаешь

Пагинация, поиск, сорт и фильтры на ресурс. Кастомные resource API — на чтение и на запись.

Swagger сразу после publish

Без ручной спеки. Открыл /api/docs после публикации типа.

Контент

Редакторам — админка, не JSON

Медиа, rich text, связи, ревизии, аналитика на дашборде — обычные CMS-задачи, уже на API.

Медиа и варианты

Библиотека, кроп, варианты картинок. Публичный /media/{id} для SPA.

Rich text и таблицы

Markdown для редакторов. Типизированные фильтры колонок, bulk delete и подписи связей в списке.

Связи и ревизии

Связи записей, история, экспорт/импорт пакетов ресурсов.

Куда угодно

Один файл. Любой PHP-хостинг.

Без Cloud. Self-host, обновление из админки, откат если swap оборвался.

install.php → zip с GitHub

Мастер качает latest, проверяет sha256, распаковывает. Если src/ уже есть — skip.

Shared-хостинг или Docker

Правильная раскладка public_html — или docker compose up с MySQL и Adminer локально.

Атомарные обновления

Settings → System. Оборванный swap откатывается. restore.php — если всё же надо пихнуть.

Безопасность в ядре

Токены, роли, хуки — без зоопарка плагинов

Auth только Bearer. Остальное уже в core.

Editor, viewer, owner

Контент-менеджер правит записи; viewer только смотрит админку. Owner → admin → editor → viewer, плюс ACL на ресурс.

OAuth + TOTP

Google / Telegram и authenticator. Капча, IP-блоки, лимиты токена по origin/IP — без охоты за security-плагином.

HMAC webhooks

Пингуй SPA или воркеры при изменении контента. Ретраи в комплекте.
